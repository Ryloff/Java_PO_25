# Time Tracker (Личный тайм-трекер)

**Time Tracker** — это настольное Java-приложение для персонального учёта времени. Оно позволяет создавать задачи, запускать таймер, работать в фоне (системный трей), строить отчёты с круговыми диаграммами и анализировать эффективность.

## Технологии и библиотеки
*   **Java 17** (или выше)
*   **Swing / AWT** (для графического интерфейса)
*   **SQLite JDBC** `3.53.4.0` (локальное хранение данных)
*   **JFreeChart** `1.5.6` (построение круговых диаграмм)

## Инструкция по сборке

Для сборки проекта используется **Maven**. Убедитесь, что у вас установлен JDK 17+ и Maven.

1.  Клонируйте репозиторий или распакуйте проект.
2.  Откройте терминал в корневой папке (где находится `pom.xml`).
3.  Выполните команду для сборки:
    ```bash
    mvn clean package
